# Wake-word models

From [openWakeWord](https://github.com/dscripka/openWakeWord) by David Scripka.

- `hey_jarvis_v0.1.onnx`: openWakeWord pre-trained model, licensed CC BY-NC-SA 4.0 (non-commercial, share-alike).
- `melspectrogram.onnx`, `embedding_model.onnx`: feature models shipped with openWakeWord (the embedding model is derived
  from Google's speech_embedding model, Apache-2.0).
